# HTML + CSS Web Page Template

A minimal, hand-written **HTML5 and CSS** template illustrating page layout,
styling and the separation of content from presentation via an external
stylesheet. A reusable starting point for simple scientific or personal pages.

## Contents

- \`HTML_CSS_00_page_template.html\` - the page structure.
- \`Polina_style.css\` - external stylesheet (typography, colours, layout).
- \`firefox-icon.png\`, \`seagrass.jpeg\` - example image assets.

## Technologies

HTML5 and CSS3.

## Usage

Open the \`.html\` file in a browser, then edit the markup and \`Polina_style.css\`
to adapt the template to your own content.
